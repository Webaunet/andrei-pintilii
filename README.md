# Jardinier Andrei – maquette de site

Maquette de site vitrine (statique) pour Jardinier Andrei, paysagiste à Andrésy (78).
Publiée avec GitHub Pages : https://webaunet.github.io/andrei-pintilii/

Pages : `index.html`, `services.html`, `realisations.html`, `contact.html`, `mentions-legales.html`.
Styles : `style.css`. Script : `script.js`. Images : `images/`.
Les pages sont générées par `outils/build.py` (`python3 outils/build.py site`) ; `outils/optimiser_images.py` prépare les images.
Les photos de chantiers viennent de la fiche Google de l'entreprise ; les autres images sont des illustrations génériques.
